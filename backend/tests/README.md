# Тесты

## Авторизация (`test_authorization.py`)

Проверяет одно правило: **посторонний не может тронуть чужой объект**.

Все находки раздела «Доступ» из аудита 2026-08-17 были однотипными: право
есть, проверки владельца нет. Любой зарегистрировавшийся по SMS получал 26
прав и вместе с ними доступ к чужим заказам, магазинам, складам и приходам —
вплоть до смены логина и пароля администратора.

Такие вещи ловятся одним параметризованным набором: для каждого метода,
меняющего или читающего чужой объект, запрос от постороннего должен давать
403. Проверять их по одному дороже, и это не мешает им вернуться.

## Как запускать

Тесты работают против **запущенного** приложения и живой базы: они опираются
на реальные данные (магазин администратора, товары) и создают своего
пользователя через SMS-вход, читая код из журнала.

```bash
./update.py local            # поднять локальный стек (mysql + бэкенд)
cd ~/Desktop/Projects/postshop_mvp
.venv/bin/pytest tests -v
```

Переменные окружения (по умолчанию — локальный стек):

| переменная | по умолчанию | что это |
|---|---|---|
| `TEST_API_URL` | `http://localhost:7002` | адрес приложения |
| `TEST_ADMIN_USER` / `TEST_ADMIN_PASSWORD` | `admin` / — (задайте) | вход сотрудника |
| `TEST_LOG_PATH` | `~/.postshop-local/logs/mvp.log` | журнал, откуда читается код из SMS |

Тесты **не меняют данные**: они только проверяют отказы. Единственная запись —
создание тестового пользователя при первом SMS-входе.
